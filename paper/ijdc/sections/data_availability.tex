Controlled-system trajectories can be regenerated with the differential-equation
and experiment code supplied in the reproducibility materials. The external
evaluation uses the NanoDrone dataset authors' publicly released,
offline-preprocessed flight-state records. To
preserve the upstream distribution terms, third-party flight files are not
redistributed. The supporting materials include data-retrieval information and
SHA-256 checksums together with configurations, seeds, split identifiers,
saved predictions, metrics, and analysis scripts. A public archival identifier
has not been assigned.
