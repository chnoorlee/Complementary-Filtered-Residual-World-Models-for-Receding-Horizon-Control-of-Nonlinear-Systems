{\sloppy Controlled-system trajectories can be regenerated with the
differential-equation and experiment code supplied in the reproducibility
materials. The external evaluation uses the NanoDrone dataset authors'
publicly released, offline-preprocessed flight-state records. To preserve the
upstream distribution terms, third-party flight files are not redistributed.
The supporting materials include data-retrieval information and SHA-256
checksums together with configurations, seeds, split identifiers, saved
predictions, metrics, and analysis scripts. The code and reproducibility
materials are publicly available at
\href{https://github.com/chnoorlee/Complementary-Filtered-Residual-World-Models-for-Receding-Horizon-Control-of-Nonlinear-Systems}{\texttt{https://\allowbreak github.com/\allowbreak chnoorlee/\allowbreak Complementary\-Filtered\-Residual\-World\-Models\-for\-Receding\-Horizon\-Control\-of\-Nonlinear\-Systems}}.
An archived release will be deposited in Zenodo and cited by its persistent
identifier in the final version.\par}
