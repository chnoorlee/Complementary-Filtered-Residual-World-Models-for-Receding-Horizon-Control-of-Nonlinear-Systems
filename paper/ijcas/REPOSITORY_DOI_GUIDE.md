# Repository and DOI route for the IJCAS manuscript

Status (2026-11-11): the public GitHub repository is created at
https://github.com/chnoorlee/Complementary-Filtered-Residual-World-Models-for-Receding-Horizon-Control-of-Nonlinear-Systems
with an MIT license and `CITATION.cff`, and the availability statement cites
it. Steps 1--3 below are complete; the Zenodo archival steps remain.

## Recommended route: GitHub plus Zenodo

1. Create a clean public GitHub repository for the CFR-WM code and
   reproducibility materials.
2. Include the executable code, frozen configurations, analysis scripts,
   environment or dependency file, a concise README, a license, and
   `CITATION.cff`.
3. Do not redistribute third-party NanoDrone files unless their license
   expressly permits it. Provide provenance and acquisition instructions
   instead.
4. Connect the GitHub repository to Zenodo and enable archiving.
5. Create an immutable GitHub release, for example `v1.0.0`. Zenodo archives
   that release and issues a version DOI.
6. Cite the version DOI in the manuscript's data and code availability
   statement. Keep the concept DOI for the repository landing page if future
   releases are expected, but cite the version DOI for exact reproducibility.

## Simpler route: direct Zenodo deposit

GitHub is not mandatory. A curated ZIP of the code and permitted data can be
uploaded directly to Zenodo. Zenodo can reserve a DOI before publication and
registers it when the record is published. This is suitable when the artifact
will not be maintained as a live software repository.

## Scope note

Depositing code or data publicly does not make the journal article open access.
The article's access model and the artifact's availability are separate.
