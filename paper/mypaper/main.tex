\section*{Data and code availability}
All trajectories are generated from the explicitly specified controlled differential equations in the accompanying code. The repository contains the generation seeds, split identifiers, trained-run metadata, trajectory-level metrics, analysis scripts, and the commands needed to reproduce every table and figure. No proprietary or real sensor data are used.
